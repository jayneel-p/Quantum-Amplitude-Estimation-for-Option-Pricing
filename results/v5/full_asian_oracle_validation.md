## What the oracle actually implements

Each fixing has its own independently prepared shock register. The circuit then (1) adds the signed shock into a cumulative register, (2) reversibly looks up the GBM fixing on the finite grid, (3) adds that fixing to the arithmetic total, (4) encodes the payoff probability, and (5) reverses all arithmetic and lookup work. No complete path vector is state-prepared.

The QCV circuit additionally computes the weighted shock sum for the geometric average, encodes the arithmetic-minus-geometric call residual, and uncomputes it. Arithmetic fixings use ceiling fixed-point rounding while the geometric average uses floor rounding.

## Proof obligations that are met

1. **No path-table loader.** The stochastic register is a tensor product of one small state preparation per fixing. Path evolution is performed after loading.
2. **Exact finite-grid objective.** For payoff numerator `p` and cap `B`, the controlled rotation angle is `2 asin(sqrt(min(p/B,1)))`; hence the objective-one probability is exactly `min(p/B,1)` up to gate/simulator floating point.
3. **Clean A-operator.** Work leakage and the explicit `A A^-1` test are reported above.
4. **Nonnegative QCV residual.** If `s_i=ceil(scale*S_i)` and `g=floor(scale*G)`, AM-GM gives `sum_i s_i >= scale*sum_i S_i >= N*scale*G >= N*g`. Monotonicity of `max(x-NK,0)` then gives a nonnegative integer call residual path by path.
5. **Exact finite-grid QCV identity.** With no cap binding, arithmetic call = geometric call + residual on every encoded path, so the same equality holds in expectation.

## What is not proved—and must not be claimed

- This does not establish accuracy for the continuous 252-dimensional GBM model. Shock quadrature, integer shock rounding, price rounding, any payoff cap, and AE statistical error require separate bounds or convergence studies.
- The reference exponential is QROM, and the current QCV residual is a rectangular QROM. At 252 coarse fixings the QCV upper bound already exceeds 23 billion lookup rows. That is a complete oracle specification, but not a credible advantage circuit.
- A publishable scaling claim needs a reversible fixed-point exponential plus comparator/subtractor payoff arithmetic, followed by Clifford+T synthesis and an end-to-end error budget. Replacing only the residual rectangle is the highest-priority engineering step.
- QAE query complexity applies to calls to this A-operator. It does not make the per-call arithmetic, state preparation, fault-tolerant synthesis, or data movement free.
